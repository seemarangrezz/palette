How publishing works

This site has no server or database, so it can be hosted for free on GitHub Pages. Every edit you make here is saved as a draft in this browser and previews live on the site straight away. To make changes visible to everyone, click Export data.js, replace /assets/js/data.js in your project with the downloaded file, then commit and push to GitHub. That's your "publish" step.
