Replace these placeholder .svg files with real photography whenever you're ready.

1. Photograph each artwork on a neutral background, in even light, straight-on.
2. Export as .jpg (photos) at roughly 1600–2400px on the long edge — large enough
   to look sharp, small enough to load fast (aim under ~500KB per image).
3. Drop the file into this folder, e.g. assets/images/artworks/my-painting.jpg
4. In /assets/js/data.js (or the Admin dashboard), set that artwork's "image"
   field to: assets/images/artworks/my-painting.jpg

You can keep using the generated placeholder art for any pieces you haven't
photographed yet — the layout is designed to look intentional either way.
